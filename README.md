# AI Prompt Maker — MMD Publishing

Aplikasi web responsif untuk menyusun prompt terstruktur dalam Bahasa Indonesia atau Inggris. Dibuat dengan HTML, CSS, dan JavaScript murni sehingga tidak membutuhkan instalasi paket atau API key.

## Fitur
- Generator prompt berbasis template, gratis dan tanpa API.
- Kategori bisnis, jualan online, media sosial, gambar AI, coding, belajar, menulis, dan umum.
- Pilihan AI tujuan, bahasa, gaya, dan tingkat detail.
- Salin prompt dan simpan/hapus favorit di browser lokal.
- Responsif untuk Android dan desktop.

## Menjalankan
Buka `index.html` di browser. Clipboard paling lancar di situs HTTPS seperti GitHub Pages.

## Publikasi melalui GitHub Pages
1. Buka repository **Settings**.
2. Pilih **Pages**.
3. Di bagian **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu tekan **Save**.
5. Tunggu proses publikasi dan buka URL yang ditampilkan di halaman Pages.

## Catatan
Versi awal ini menyusun prompt memakai template lokal. Ini bukan chatbot dan tidak mengirim permintaan ke model AI. Favorit tersimpan di browser/perangkat yang digunakan dan tidak tersinkron otomatis. Jangan masukkan informasi rahasia ke prompt.
